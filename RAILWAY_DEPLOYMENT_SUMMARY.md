## 📋 Deployment Steps

### 1. Prerequisites
```bash
# Install Railway CLI
npm install -g @railway/cli

# Login to Railway
railway login
```

### 2. Create Project
```bash
# Create new Railway project from GitHub
railway new
# Select "Deploy from GitHub repo"
# Choose your repository
```

### 3. Add Databases
```bash
# Add PostgreSQL database
railway add postgresql

# Add Redis cache
railway add redis
```

### 4. Set Environment Variables
Copy variables from `railway-env-template.txt` to Railway dashboard:

**Backend Service:**
- DATABASE_URL (auto-generated by Railway PostgreSQL)
- REDIS_URL (auto-generated by Railway Redis)
- SECRET_KEY (from generated-keys.txt)
- MASTER_ENCRYPTION_KEY (from generated-keys.txt)
- MISTRAL_API_KEY (your API key)
- ENVIRONMENT=production
- DEBUG=false

**Frontend Service:**
- NEXT_PUBLIC_API_URL (your backend Railway URL)

### 5. Deploy
```bash
# Deploy both services
railway up
```

## 🛠️ Troubleshooting

### Common Issues & Solutions

1. **Build Failures**
   - Check Railway deployment logs
   - Verify requirements.txt/package.json
   - Ensure Python 3.11+ compatibility

2. **Runtime Errors**
   - Verify environment variables
   - Check database connection strings
   - Review application logs

3. **CORS Issues**
   - Update ALLOWED_HOSTS with Railway URLs
   - Ensure frontend URL is whitelisted
